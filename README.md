# DSA practice in Java

Brute-force and optimal reference solutions, with explanations, complexity and a pattern to remember.

Each question lives in:

```text
<topic>/<question-number>-<question-name>/
  README.md
  Solution.java
```

Each problem README records one of these statuses:

- `Solved by me`
- `Reference solution (to attempt)`

Generated reference solutions start as `Reference solution (to attempt)`. That status changes after I code the problem myself.

Daily coverage is scheduled for 9 am and 5 pm IST, with one commit per question:

```text
Add: <question no> - <name> (<topic>, <difficulty>)
```

Already solved and previously covered questions are skipped. Each Java solution is compiled and checked against examples and edge cases before publication. Where a source-list label differs from its linked problem, the problem README records the difference and follows the linked statement.
